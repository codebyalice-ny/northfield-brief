      Method & AI Workflow

      How the numbers are produced and checked

      1. Weekly export. One row per channel per week: spend, impressions, clicks, conversions, revenue and new customers (synthetic practice data, 12 weeks, 7 channels).
      2. Rules file for Claude. A written brief_rules.md tells Claude how to combine the files, which checks to run first, and the one-page brief format, so every week uses the same method.
      3. Data checks before analysis. Missing revenue, missing or duplicate channel rows, and week-on-week moves over 50% are flagged before any recommendation.
      4. Excel cross-check. An Excel workbook with live formulas recalculates every total, so the brief's numbers can be traced back to the source rows.
      5. Know the limits. These are last-click, platform-style numbers. Independent measurement would test which channels are truly incremental and how much headroom each has before returns fall.
